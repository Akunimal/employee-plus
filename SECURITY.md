# Security Policy

Employee+ is a hackathon MVP and must not be used with real customer, payment, tax, medical, or access-control data.

Do not commit credentials, OAuth secrets, tokens, personal data, Ring media, or AWS keys. Report security issues privately to the repository owner rather than opening a public issue with sensitive details.

The planned service will use explicit confirmation for consequential actions, tenant-scoped authorization, idempotency, signed Ring events, redacted logs, and synthetic demo data.
