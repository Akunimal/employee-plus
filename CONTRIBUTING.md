# Contributing

Employee+ is a greenfield hackathon project. Contributions must preserve the public contracts, tests, security boundaries, and synthetic-data limitation.

Before opening a pull request:

1. Run the documented checks.
2. Add or update tests for behavior changes.
3. Update `ROADMAP.md` or the relevant ADR when a public decision changes.
4. Do not include credentials, personal data, video, audio, or generated build output.
