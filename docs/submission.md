# Hackathon submission checklist

Employee+ will submit Alexa+ as its primary track. Ring remains a conditional track and may only be named in the submission after R0 and M5 have passed using the official Ring developer simulator/API. The video is English, under three minutes, and shows the actual remote MCP endpoint, consumer workflow and the relevant technology at runtime.

Before submission, replace the placeholder domain in `addon-package/addon.json`, run the official MCP and Alexa+ inspectors, attach sanitized evidence, record product feedback, and confirm the public GitHub repository contains the Apache-2.0 license and reproducible local setup.
